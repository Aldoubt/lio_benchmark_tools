## 启动

```bash
cd /home/yangxuan/lio_benchmark_tools
source /opt/ros/humble/setup.bash
source /home/yangxuan/agt_navigation_v2/install/setup.bash

benchmark_base/bin/lio-benchmark validate \
  --config benchmark_base/config/mapping_20260719_172810.json

benchmark_base/bin/lio-benchmark doctor \
  --config benchmark_base/config/mapping_20260719_172810.json

benchmark_base/bin/lio-benchmark run \
  --run /home/yangxuan/lio_benchmark_runs/mapping_20260719_172810_full807_round1_001
```

算法会按 manifest 顺序串行执行；单个算法失败后会继续后续算法，结果写入各自的 `raw/<algorithm>/`。当前 run 已初始化，不要再次执行 `init`。


性能曲线输出到 `$RUN/figures/resource_curves/`：

- `resource_curves.png`: CPU、RSS、线程数随时间曲线
- `resource_summary.png`: 均值/峰值资源柱状图
- `resource_timeseries.csv`: 全部算法的原始时间序列
- `resource_summary.csv`: 算法级汇总

## 交互式三维查看器

```bash
benchmark_base/bin/lio-benchmark-viewer \
  --run "$RUN"
```

查看器使用同一 FAST-LIVO2 基准坐标系显示标准化路径和 PLY 点云。左侧可以勾选算法、修改颜色、切换路径/点云显示和预设视角；三维窗口支持鼠标旋转、平移和滚轮缩放。性能曲线页签显示 CPU、RSS、线程数曲线和资源汇总图。Point-LIO 重跑并重新生成地图后，查看器会自动发现新的结果。
