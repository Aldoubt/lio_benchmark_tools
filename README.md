# lio_benchmark_tools

A reproducible ROS 2 LIO/SLAM benchmarking workspace for MID360-style datasets, with algorithm wrappers, health checks, trajectory standardization, resource monitoring, diagnostics, and comparison/reporting tools.

> This feature branch keeps the existing top-level project overview unchanged in scope. Phase-aware benchmark details live in `benchmark_base/docs/PHASE_AWARE_BENCHMARK.md` and the draft PR so that experiment-specific notes do not replace the repository overview.
